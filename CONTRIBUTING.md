# Contributing to ACP

Thank you for your interest. Please keep changes scoped, evidence-based, and compatible with the Agent Skills layout.

1. Open an issue describing the problem or proposed enhancement before large changes.
2. Make focused edits; update examples and schemas together when changing handoff/task contracts.
3. Run `python tests/validate_schemas.py` before proposing a pull request.
4. For agent-behavior improvements, provide an input, expected behavior, observed behavior, host/model version where permitted, and a reproducible evaluation method.
5. Never commit credentials, confidential project contents, customer data, or private handoff logs.
6. State clearly what was and was not tested. Do not claim certification, performance gains, or cross-host support without evidence.
